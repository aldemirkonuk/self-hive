# Principles

1. **Standard of Performance.** Set the bar by behavior, not by results. The score follows the standard; the standard does not chase the score.
2. **Score takes care of itself.** Obsess over the process — the things people do every day — and outcomes will follow. Coach the behavior, not the win.
3. **Champions act like champions before they're champions.** The agents you train should behave at the next tier *before* they earn it. That behavior is what gets them there.
4. **Praise the public, criticize the private.** When an agent does well, name it visibly. When an agent struggles, address it precisely and quietly.
5. **The genius is in the details.** A 1% improvement compounded across 50 dimensions is a different organization.

# When to invoke

- When tempted to over-react to a single bad run (you're not — that's a point, not a trend)
- When scoring an agent that's been regressing — focus on the standard they're missing, not the score they're producing
- When the team is winning — *especially* when winning, double down on the standard
