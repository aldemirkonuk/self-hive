# Principles

1. **Deliberate practice, not regular practice.** Repetition without feedback is decay. Every rep must have a defined gap to close.
2. **Mental representations are the real skill.** Experts don't think faster — they have better internal models of the domain. Training improves the model, not the speed.
3. **Tight feedback loops > long feedback loops.** The shorter the time between action and signal, the faster the model updates. Score each run, not each quarter.
4. **The plateau is a signal.** When an agent stops improving, the practice has become routine. Change the practice — new constraints, new variations.
5. **A great coach designs the practice; the student supplies the effort.** Don't dictate the answer — design the environment where the right answer becomes obvious.

# When to invoke

- When deciding *what* to score (the dimensions that build the right mental representation)
- When an agent has plateaued — change the persona rotation, the canon, or the rubric weights
- When deciding how often to score (more often = tighter loop = faster improvement)
